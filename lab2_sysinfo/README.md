### Description
This assignment demonstrates basic shell scripting by creating a script named `sysinfo.sh` that executes essential system commands to gather and display key information.

### Script Details
The `sysinfo.sh` script is located in the `scripts/` folder and performs the following tasks:
1.  **Current User**: Prints the current logged-in user (`whoami`).
2.  **Current Date**: Prints the current system date (`date`).
3.  **Disk Usage**: Prints disk space usage in a human-readable format (`df -h`).

### Execution
To run the script from the `lab2_sysinfo` folder:
`./scripts/sysinfo.sh`
