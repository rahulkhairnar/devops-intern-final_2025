# Loki Monitoring Setup Documentation

This file documents the steps taken to configure a local monitoring stack using Docker Compose.

## 1. How Loki and Promtail were started

The entire stack (Loki, Promtail, Grafana) is defined in 'monitoring/docker-compose.yml'.

**Start Command:**
To run the services locally using Docker (from the `lab6_Grafana_Loki` directory):
```bash
cd monitoring
docker-compose up -d
```
This command starts:
1.  **Loki (Port 3100):** The log storage backend.
2.  **Promtail:** The log shipping agent.
3.  **Grafana (Port 3000):** The visualization layer.

## 2. Command to view logs (Grafana Interface)

**Steps to View Logs in Grafana (After starting the stack):**
1.  Open your browser to: `http://localhost:3000`
2.  Go to the **Explore** tab.
3.  Ensure the **Loki** data source is selected (you may need to configure it once to point to `http://loki:3100`).
4.  **Use the Log Query Language (LogQL) to query logs:**

**Log Query Command Example:**
To find all logs from our application container:
```logql
{job="devops-app"}
```
This query targets the label 'job: devops-app' that Promtail is configured to assign to our application's container logs.
